## 仍需实机检查 / 边界

- 新 ZIP 的浏览器麦克风、接近 55 秒录音、取消，以及 Windows 真机完整流程不能用合成音频或模拟测试替代。

- 旧 Sites 仍为 public，但普通 Node 请求仍可能被 Cloudflare HTML 403 拦截；新 SCF 没有修改或绕过它。H5 语音保持原站点路径。
- 当前 Sites 未配置 TokenHub 视觉密钥，不能把 H5 的直接云端照片识别称为已启用；ZIP 的 WorkBuddy 照片流程不依赖该密钥。
- 默认 Function URL 是腾讯提供的测试入口，长期生产须绑定自定义域名。应用限额不是云账户消费硬封顶；公网请求、COS 操作仍可能产生费用。
- 每 IP 每分钟 5 次、UTC 每日 30 次、全站每日 100 次。H5 与 ZIP 是独立计数服务，并非合并后的全账户 100 次上限；同一现场网络可能共享 IP 额度。
