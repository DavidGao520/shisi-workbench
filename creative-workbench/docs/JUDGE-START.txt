食肆工作台 · 最终评委体验包（2026-09-10）
========================================

请先完整解压，再按下面四步打开。完整图文操作说明见同目录 README.md。

1. 安装并登录 WorkBuddy 桌面版
   官方下载：https://www.workbuddy.cn/work/
   Windows 10+：下载 Windows 安装包，双击按向导安装。
   macOS 12+：M 系列选 Apple / ARM64；Intel 选 Intel / X64。
   Mac 打开 dmg 后，将 WorkBuddy 拖入“应用程序”。
   打开 WorkBuddy，用自己的账号登录，不用参赛者账号。

2. 安装 Node.js（本机连接程序的运行工具，不是模型）
   官方下载：https://nodejs.org/en/download
   版本选 22.x LTS（不低于 22.13）：Windows 用 msi，Mac 用 pkg。
   已有可在本机运行且符合版本的 Node.js 无需重装。
   装完请完全退出并重新打开 WorkBuddy。
   不需要安装 Git、Python、Whisper、uv、语音模型，也不需要 API Key。
   不需要运行 npm install 或编译源码。

3. 完整解压 ZIP，打开正确的文件夹
   Windows 右键 ZIP → 全部解压；Mac 双击 ZIP。
   不要在压缩包预览里运行，不要只提取 HTML。
   在 WorkBuddy 新建任务时选择解压根文件夹作为工作空间。
   这一层应同时有 中华食肆.html、README.md、skills 和启动文件。

4. 将下面这段话发给 WorkBuddy

请把当前选中的文件夹作为食肆工作台的完整体验包。先阅读根目录 README.md，
再读取并遵循 skills/zhonghua-shisi/SKILL.md 及其启动所需的引用文档，
检查 Node.js 版本，按说明启动本机连接并打开返回的页面。
只启动和使用工作台，不修改 HTML、CSS、菜谱或布局，不下载模型，不索取 API Key。
遇到问题请告诉我缺少哪一步，不要搜索其他项目或强制停止未知进程。

核对后允许 WorkBuddy 在本文件夹内读写、执行配套脚本即可，不必开启全局权限。
这是在当前任务读取随包 Skill，不是自动安装到所有对话。新对话请重新发送提示。

成功入口：http://127.0.0.1:43117/
默认是样例厨房，可立即看导览、推荐菜与百味图中的六道真实实拍食忆。
返回自己的厨房：点右上角“返回我的真实厨房”。两边数据独立。

再次打开：Windows 双击 Start-Windows.cmd；Mac 双击 启动厨房.command。
结束使用：Windows 双击 Stop-Windows.cmd；Mac 双击 停止厨房.command。
也可以继续让 WorkBuddy 按 Skill 启动/停止。停止连接不删除库存。

照片识别：网页“我的厨房 → 拍照识别 → 准备接收照片识别”，复制提示词，
在加载本包 Skill 的同一个 WorkBuddy 对话上传照片并发送；回网页核对后入库。
语音录入：在网页点语音按钮并允许麦克风，联网转写后核对入库。
语音、WorkBuddy 照片识别需联网与相应服务可用；手动添加和预设菜谱可离线用。
新入库未填到期日，默认确认当天的 7 天后，仅作提醒，不是保质期保证。

常见问题：
- 网页打不开：先确认 Node.js、完整解压、正确文件夹。看 README.md 的排查部分。
- 43117 被占用：先从旧工作台目录正常停止旧连接，不强杀未知程序。
- 字太小或页面比例不对：浏览器按 Ctrl+0（Mac 为 ⌘0）恢复 100%，不要改 CSS。
- 系统拦截脚本：不要关闭全局安全保护；让 WorkBuddy 在授权范围内运行配套程序。
- 语音暂不可用：可直接输入文字，不用安装模型或提供密钥。

不要删除自己的浏览器数据。需要留存时先导出备份，当前没有整库恢复界面。
