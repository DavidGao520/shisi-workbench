# 食肆工作台 · 评委使用说明

从游戏的一餐到生活的一餐。国宴队将高源与 Jacky 共同创作的《中华食肆》中的菜品、插画与故事，复用为一个非游戏的家庭厨房工作台：识别食材 → 人工核对入库 → 挑选家常菜 → 分步跟做 → 成品照、评分与食忆 → 点亮百味图。

本包以 **评委在自己的 WorkBuddy 中加载随附 Skill，并允许运行配套程序** 为使用前提。照片识别用 WorkBuddy；网页麦克风用工作台已部署的腾讯云语音 API。**不需要下载 Whisper、Python、uv 或语音模型，也不需要填写 API Key。** 不依赖参赛者电脑开机，但语音需要联网且云端服务正常运行。不是双击 HTML 即可使用全部 AI 功能的离线包。

**最终体验版 · 2026-09-10。** 请使用与本说明一同收到的完整 ZIP，不要混用旧版 HTML 或旧启动文件。包内 `VERSION.json` 记录对应的 GitHub 提交与各文件校验值；这是版本核对信息，评委无需编辑。

## 1. 准备与打开（Windows / macOS）

### 第一步：下载并安装 WorkBuddy

打开 [WorkBuddy 官方下载页](https://www.workbuddy.cn/work/)，下载**桌面版 WorkBuddy**，不是 CodeBuddy IDE 或命令行工具。

- **Windows：** 使用 Windows 10 或更新系统，下载 Windows 安装包，双击后按安装向导完成。
- **macOS：** 使用 macOS 12 或更新系统；苹果 M 系列芯片选 Apple / ARM64，Intel 芯片选 Intel / X64。打开下载的 `.dmg`，把 WorkBuddy 拖入“应用程序”，再从“应用程序”启动。可在苹果菜单“关于本机”查看芯片。
- 打开 WorkBuddy，点击“登录”，在浏览器按页面提示用自己的账号登录，完成后返回客户端。不需要参赛者的账号、密码或密钥。

官方详细步骤：[Windows 安装与登录](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide)、[macOS 安装](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Mac-Guide)。菜单名称可能随客户端更新略有变化。

### 第二步：安装工作台需要的 Node.js

本包的本机连接程序需要 **Node.js 22.13 或更新版本**。从 [Node.js 官方下载页](https://nodejs.org/en/download) 的版本选项中选择 **22.x LTS（不低于 22.13）**：Windows 用 `.msi` 安装包，Mac 用 `.pkg` 安装包，按向导安装即可。已有可在本机正常运行且符合版本的 Node.js 不必重复安装。较旧的 macOS 不要直接选择最新版 Node.js；按这里的 22.x 版本安装。

安装后**完全退出并重新打开 WorkBuddy**。可让 WorkBuddy 检查 `node --version`，应为 `v22.13.0` 或更新版本。Node.js 是配套程序的运行工具，不是模型；评委**无需运行 npm install、编译源码或安装 Git、Python、Whisper、uv、模型文件**。

### 第三步：完整解压体验包

Windows：右键 ZIP →“全部解压”，选本机可写目录，例如 `C:\ShisiWorkbench`。Mac：双击 ZIP，再把整个解压文件夹放入“文稿”等本机可写目录。不要只提取 HTML，不要在 ZIP 预览里运行，建议避开网盘同步目录。

打开解压文件夹，应同时看到 `先读我.txt`、`README.md`、`中华食肆.html`、`skills` 文件夹和四个启动/停止文件。**选中包含这些文件的这一层文件夹**，不要选 ZIP 文件或内层 `skills` 文件夹。

### 第四步：在 WorkBuddy 打开文件夹并启动

在 WorkBuddy 新建任务时，用文件夹选择器把上一步的完整文件夹设为工作空间。随后把下面整段话发给 WorkBuddy；如果已选好文件夹，不必再填写路径：

WorkBuddy 请求在**这个文件夹内**读取文件、写入运行数据或执行配套程序时，核对后批准即可；不必开启全局完全访问。此方法是让当前任务读取并遵循随包 Skill，**不代表已经安装到技能市场或会被所有新任务自动加载**。换了对话，请重新发送启动提示。

若希望在客户端正式安装技能，可参考 [官方技能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)，保留技能的脚本和引用文件。本体验包 ZIP 是完整应用包，不要当成已经验证过的“技能上传包”直接导入。评委按上面的任务读取方式即可体验，无需先发布技能。

成功后打开 **http://127.0.0.1:43117/**，默认进入**样例厨房**：首次使用已备好 22 项食材和调料，并开始五站参观；重开会保留样例修改和参观进度。百味图包含 35 条标注为演练的样例，以及作者本人真实做过的 6 道菜的照片和食忆，共 41 条记录、38 道点亮菜品（部分菜品同时有两类记录）。六道实做菜排在百味图前面，点开可看完整实拍。右上角点“返回我的真实厨房”，即可切到自己的厨房，两边数据互不影响。能看到“今日一餐 / 我的厨房 / 做菜模式 / 百味图”。

也可双击本包启动文件（启动网页后，照片仍需在已加载 Skill 的 WorkBuddy 对话上传）：

## 2. 完整体验一次

**到期日期。** 语音、拍照、手动添加及调料清单新建库存时，未填写到期日就默认保存为确认入库当天的 7 天后；填写了日期则保留。默认日期只作提醒，不代表保质期或安全保存承诺。盘点已有批次时留空不修改原日期，旧库存不会自动延长期限。

**拍照与入库。** 想录入自己的食材时，先点右上角“返回我的真实厨房”，再到左侧“我的厨房”选择家里有的调料；进入“拍照识别”，点击居中的“准备接收照片识别”，复制页面上的提示词。随后在**同一个 WorkBuddy 对话**上传食材照片并发送提示词。识别结果到达后，页面自动转到待确认食材，核对数量、单位和到期日期，再确认入库。照片默认按盘点处理，不自动累加库存。AI 不判断保质期、新鲜度，也不擅自入库；照片没看清时可重拍或手动补充。

**选菜与跟做。** 从“今日一餐”推荐或“百味图”选择一道菜，查看用料、可展开的“烹饪流程”和“参考文献”。72 道预设做法随时可用，包含工作台新增的辣子鸡与青椒茄子；缺少库存记录但实际已备齐的用料可点“确认拥有”，只用于本餐，不额外入库。全部备齐并勾选食材/到期信息/过敏原/厨具核对后开始，按步骤和本步计时跟做，可暂停保存。

**留下一餐。** 完成后可上传成品照，分别评价好吃程度、制作难度、卖相程度；难度为 **1 星困难、5 星简单**。可留一句家庭记忆或下次改进，确认完成后在百味图查看记录。成品照上传不是食材 AI 识别，评分始终由本人填写。

**可选：让 WorkBuddy 另写做法。** 在菜品详情展开对应入口、准备任务，再回 WorkBuddy 说“读取厨房任务，生成做菜步骤”；网页收到草稿后由你核对。没有主动发起这项任务，不影响预设做法。

本地体验版默认从样例参观开始；切到真实厨房后，仍可点“先逛逛样例厨房”返回。样例与真实厨房分开；演练不代表实际做过或实拍识别成功。旧样例升级时只补入缺失的六条作者记录，保留已有库存、食忆与参观进度；只有主动确认“恢复初始样例”才会重置为完整初始样例，不影响真实厨房。

## 3. 网页麦克风（云端 API）

Windows 与 macOS 操作相同：启动厨房 → 点击“语音录入” → 允许浏览器使用麦克风 → 说“冰箱里有两个鸡蛋、三个西红柿” → 结束录音 → 核对清单 → 确认入库。不需要语音初始化。

每段最多约 55 秒。录音通过本机配套程序转交到工作台云端 API，再由腾讯云转写；密钥只在服务端，ZIP 不包含密钥。工作台不保存录音文件；音频会发送给腾讯云，不能视为离线识别。照片仍由 WorkBuddy 识别，不改用语音 API。

网络不通、访问被拦截、服务维护或次数用完时会明确提示，可直接输入食材继续体验；不会偷偷改用本机模型。共用现场网络的设备会共享 IP 限额，请勿连续反复录制测试。

## 4. 常见问题与边界

- **整个页面很小 / 右侧空白 / 卡片被拉得很宽：** 先查看浏览器菜单中的页面缩放。可用 macOS `⌘0`、Windows `Ctrl+0` 恢复 100% 后再判断；需要更大字体时可自行放大。工作台的桌面侧栏和内容区有固定尺寸与阅读宽度上限，超宽屏上的留白不代表 ZIP 缺少内容。不要为铺满窗口删除宽度上限、加入 CSS 缩放或修改源 HTML。仍异常时保留截图，并记录浏览器缩放和窗口大小交给维护者；在 WorkBuddy 分屏预览中也可打开同一本机地址到独立浏览器比较，不清理库存或浏览器数据。
- **双击打不开 / 提示缺依赖：** 请从本机完整解压的目录运行，按说明安装 Node.js 后重开终端。若脚本被系统安全策略阻止，不关闭全局安全保护；请 WorkBuddy 在授权范围内运行配套 Node 程序，或请设备管理员协助。
- **43117 被占用 / 连不上：** 先在旧工作台目录运行“停止厨房”，再启动这份；不强杀其他进程、不换端口、不清库存。浏览器未自动打开时手动打开上方地址。WorkBuddy 内嵌预览打不开时，用本机 Edge / Chrome 打开同一地址。
- **图片结果没有回来：** 确认网页正在等待，照片发到了加载本包 Skill 的同一 WorkBuddy 对话，并允许它运行脚本。工作目录必须是本包，而不是另一个项目。网页不会自动唤醒 WorkBuddy。
- **语音无响应：** 检查网络和浏览器麦克风权限。若提示 403 / 访问保护拦截，请联系维护者检查云端入口；若额度已用完，请稍后重试或直接输入。无需安装模型或提供密钥。更新旧包后先停止旧连接，再用新版启动并刷新网页。
- **换电脑后记录不见了：** 库存、成品照、评分在原浏览器本机保存，不随 ZIP 同步。升级时保留原目录和同一浏览器入口，先导出完整备份；当前无整库恢复界面，不要删除旧数据。

照片识别及可选做法依赖 WorkBuddy 账号能力、网络与本机执行权限；语音依赖云端 API。菜谱与手动闭环可离线使用。菜谱时间与份量为家庭改编估计，参考来源不代表逐道实做认证；实际操作须自行核对熟度、过敏原和厨具。
